# 高高度の外階段とワープ

高層塔の屋上から通路でつながる浮遊建物に、各階・屋上を往復できる外階段を追加しています。飛行やジャンプは不要です。階段は塔からの通路がない3辺のうち1辺に設置します。設置面は島シードと専用の用途値 `0x53544149` で選び、再訪しても同じです。建物の階数やワープ装置の乱数列には影響しません。

浮遊建物のある島（原点からの距離が6以上）では、最下階から屋上までのいずれか1階をワープ階に選びます。階と8台の装置の距離は、島座標・ワールドシード・専用の用途値 `0x57415250` から作る xor128 で決まり、再訪・再起動しても同じです。建築などの乱数列は消費しません。

## 操作と行き先

装置の正面から近づいて見ると、方角と距離の案内が出ます。**E**で調べると、色ずれ・横方向の断裂・ノイズが広がり、到着先で少し落下しながら画面が戻ります。演出は約3秒を目安にし、生成が間に合わなければ崩れた状態を延長します。人との会話中は作動しません。壁越しや背後の装置は選択しません。

- 東西南北の距離は30〜70島、斜め4方向は20〜50島です。両端を含みます。
- 方角は建物の回転に影響されません。北は島座標の−Z、東は+X、南は+Z、西は−Xです。
- 北47なら `(X, Z-47)`、南西25なら `(X-25, Z+25)` へ移動します。
- Eの処理は島の生成を待たずに戻ります。到着先1島をバックグラウンド生成し、床と当たり判定ができてからワープ階の中央へ移ります。ワープ階がない島では、壁付き階段塔の安全な屋上へ移ります。
- 周囲は出現位置から近い島を優先して順次生成し、GPUへの島の登録は1フレームに最大1島です。近い9島が準備できてから画面を戻し始め、残りも通常のストリーミングで補います。元の景色は到着先の準備ができるまで維持します。
- 出現位置は床から足元が1.1単位高い場所です。飛行・以前の落下速度を解除し、画面が戻る段階で短く落下して着地します。演出中の移動・最初の島への移動・保存・手動の視点復元は受け付けません。到着先1島の生成に失敗した場合は元の場所で画面と操作を戻します。
- 64bit島座標の範囲外へ出る装置は作動せず、案内を表示します。

ワープ階の床には、その島の番号を同一平面のパネルとして埋め込みます。数字の下に下線を入れ、上下が分かるようにしています。長い番号は最大8桁ずつ折り返します。

ワープの確認で「はい」を選び、実際にワープが始まると専用のワープ音が一度だけ鳴ります。確認の表示やキャンセルでは鳴りません。音量は `AudioDirector.WarpVolume` で調整できます。

## 検証

```powershell
dotnet run --project CAERO -- --warp-test
dotnet run --project CAERO -- --capture-warp --identity-cell=-43,-33
dotnet run --project CAERO -c Release -- --warp-render-test
dotnet run --project CAERO -- --capture-warp-transition
```

`--warp-test` は8シード・3島で再生成、全4回転、内部階と屋上、距離・座標計算、支持床・出現空間を確認します。外階段の設置面の再現性と3辺すべての往復を、実際のプレイヤー物理で確認します。装置への経路、到着先の生成、屋上への代替到着、落下着地も確認します。通常の `--movement-test` にも含みます。

非同期ワープについても、生成を意図的に待たせて更新処理が継続すること、床の準備前に移動・落下しないこと、出現位置からの生成順、1フレーム1島の登録、生成失敗時の復帰・未完了処理のキャンセルを確認します。

`--warp-render-test` は実際のOpenGL描画を続けながらワープし、Eの処理時間・フレーム数・更新時間・着地を計測します。`--capture-warp-transition` は出発・最大の崩れ・到着・復帰途中・通常画面を撮影します。計測JSONと画像はDebugでは `SaveData/`、Releaseでは実行ファイルの隣に出力します。どちらも音声とセーブの読み書きは行いません。

2026-10-22のRelease実測（シード1701、`(-43,-33)` から北46島、1440×900、音声なし）では、Eの起動処理2.62ms、演出3.02秒・181描画フレーム、最大更新時間14.37ms、最大フレーム時間23.45msで到着・着地しました。Debug / Releaseビルド、非同期ワープ検証と、418本の経路を含む全体移動テストも通過しています。

`--capture-warp` は外階段・床番号・装置の並び・Eの操作案内を4枚撮影します。島座標を省略すると `(15,0)` を使います。保存済みの視点は読み書きしません。
