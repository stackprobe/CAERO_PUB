# CAERO5 の深海の巨大魚

全長約25単位の暗い巨大魚を、現在地周辺の海に1体だけ管理します。大きな体、背ビレ・胸ビレ・尾ビレ、開閉する顎と歯、鈍い黄緑色の目を手続き生成しています。尾と後半身をゆっくりくねらせ、襲撃時は速く動かします。目以外の部位は発光せず、周囲を照らす光源も追加しません。既存の水中の濁り・減光で遠い魚の体は暗く隠れ、近づくと輪郭が見えます。輪郭付近だけにごく弱いポストエフェクトのぼかしを加え、水になじませています。体は海底より暗い輪郭にし、目を頭部の前へ出して黄緑色の発光と淡いブルームを加えます。目は昼夜や水深によって暗くならず、自発光には距離による減衰を適用し、石材の裏から透けて見えることはありません。

## 行動

- 通常は島同士の間を毎秒約1.1単位で自由に巡回します。中心は海底から約5単位（Y=-59付近、水底はY=-64）で、上下の揺れは最大約0.25単位です。体は水平に保ち、腹・ヒレ・尾が海底に接触しない範囲で低く泳ぎます。
- 視点が水面下0.4より深い連続潜水時間に応じて段階的に変化します。0〜5秒未満は自由遊泳、5〜15秒未満は主人公に近い海域の交点へ毎秒約2単位で移動、15〜25秒未満は主人公の真下付近へ毎秒約4単位で近づきます。準備段階では海底付近を維持し、目的地付近で待機します。
- 25秒で襲撃へ切り替え、主人公自身へ毎秒約11単位で向かいます。この段階だけ浮上して水面近くまで追い、約0.6秒で顎を開きます。25秒は襲撃開始までの時間で、実際に接近するまでには距離と回り道に応じた時間もかかります。
- 水中で魚の中心から28単位未満になると、潜水時間や準備段階に関係なく即座に襲撃へ切り替えます。一度襲撃を始めると範囲外へ離れても追跡を続け、浮上すれば解除します。水中の飛行モードでも同じ条件です。起動・復帰直後の猶予中は襲いません。
- 開いた口からプレイヤーの体の中心まで3.5単位以内で、間に壁がなければ飲み込みます。体や尾に触れただけでは飲み込みません。血や負傷の表現はありません。
- 浮上して視点が水面下0.4より浅くなると、潜水時間をリセットし、巡回へ戻ります。陸上や水面より上の飛行では襲いません。

Nキーは従来どおり昼夜の進行だけを変更し、魚や潜水時間を10倍速にはしません。ウィンドウが非アクティブな間は魚のシミュレーションを止めます。

## 飲み込まれた後

`World.Views[0]` が指す最初の島の本来の開始地点へ戻します。移動前に周囲5×5区画を同期的に生成し、落下速度・飛行・遊泳・移動音の状態をリセットして会話も閉じます。短く暗転し、「……気がつくと、最初の島に戻っていた。」と表示します。潜水時間を0に戻し、10秒の猶予を設けて直後の連続襲撃を防ぎます。ワールドシードや建築は変わりません。

通常の起動・1/F9で移動した後は3秒の猶予を設けます。魚の巡回位置・警戒状態・潜水時間は保存しません。

## 地形と寿命

魚は体の長さに沿って4個の半径7の球を置き、体・ヒレ・尾を含む保守的な範囲で地形・柱との衝突を確認します。平らな海底に対しては、横幅の大きい球ではなく、開いた顎・ヒレ・傾いた尾を含むモデルの下面で確認します。これにより海底近くのプレイヤーにも口が届きます。高速移動は1/30秒以下に分割し、並進と旋回の途中も0.2単位・約0.08ラジアン以下で調べます。

上下の移動と体の傾きを分け、海底近くでは体を水平に保ちながら深度を変えます。左右の旋回も独立して行い、真後ろの相手へ振り向けない問題や、反転で腹を上にしてしまう動きを防ぎます。曲がる間は減速し、相手が体の横まで入った場合はいったん距離を取って口を向けます。進めない場合は方向を変え、深度の変更や後退を試します。壁越しに噛むことも防ぎます。

追跡先まで直進できないときは、島の間の交点を海中の経由点とする経路を探索します。交点間の縦横の経路は橋脚の間を通り、候補の線分ごとに全身の衝突範囲を検査します。距離を最小にする経由点列を選び、実移動でも従来の旋回・移動途中の衝突検査を通します。毎秒直進への復帰を確認し、相手が8単位以上動けば経路を再探索します。浮上・初期化・飲み込み後は経路を破棄します。

配置候補は島の間の交点です。シードから向きを決め、全身が地形や海底に重ならない場所だけを採用します。遠くへ移動して現在地と384単位以上離れると、新しい周辺海域へ再配置します。この自動再配置では連続潜水時間・残りの猶予時間・既に始まった襲撃を引き継ぎます。浮上・明示的な移動・飲み込みでは従来どおりリセットします。移動距離に応じて敵を蓄積しません。描画メッシュ3個は共有し、終了時に解放します。

視点が水面上0.25単位より下へ来た時点で、入水地点を中心に配置し直します。再度の入水を受け付けるのは水面上0.4単位より上に出た後で、水面での揺れや連続潜水によって警戒時間が繰り返しリセットされることを防ぎます。残りの復帰猶予は引き継ぎます。島間の交点で4方向の向きを試し、すべて不適切なら入水地点の下と半径24〜96の候補を探します。配置できず非アクティブになった場合は1秒ごとに現在地付近で再試行します。

## 確認

CAERO5フォルダーから:

```powershell
dotnet run --project CAERO -c Debug -- --predator-test
dotnet run --no-build --project CAERO -c Debug -- --capture-predator
dotnet run --no-build --project CAERO -c Debug -- --capture-predator --night
```

`--predator-test` はウィンドウなしで、0/5/15/25秒の状態・目標位置・海底付近の水平移動・襲撃時の浮上・浮上後の海底への復帰・各準備段階での近接による即時襲撃・近接範囲の内外・範囲外への追跡継続・自動再配置時の潜水時間維持を3種類のフレーム時間で検証します。さらに、従来の遠方配置と入水時の配置の両方からの54追跡（3シード・スタート島の四方・対角・海の階段付近・浅瀬・海底）と移動する相手への6経路再探索を、全身が地形をすり抜けず実際に飲み込むまで検証します。従来の深海の低速巡回、接近と長時間潜水による警戒、向き直り・追跡・飲み込み、3種類のフレーム時間での開始地点復帰、復帰後の猶予、浮上での追跡終了、水上と水中の飛行の違い、真後ろ・上方・海底にいる相手と全8方向の追跡、柱・薄い壁・海底と沿岸追跡の衝突、遠距離移動後の1体の再配置も検証します。全8方向は同じ深さと海底の2通りで実際に飲み込むまで確認します。入水時の配置は3シード・21か所と巨大な島座標で確認し、水面の揺れ・連続潜水・再入水・配置失敗からの復帰も検証します。同じ検証を既存の `--self-test` / `--stream-test` にも組み込んでいます。

`--capture-predator` は遠くの目・正面への接近・側面の巨体・開いた顎・実際に飲み込まれた後の復帰画面の5視点を撮影し、`SaveData/Captures/generated-predator-*.png` に保存します。夜は `generated-predator-night-*.png` です。撮影・検証は通常プレイのセーブを変更しません。
