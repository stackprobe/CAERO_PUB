# CAERO5 の音

効果音と水中の環境音は `AudioSynthesis.cs` の合成音を維持し、起動時に22,050 Hz / 16 bit / ステレオPCM WAVをメモリ上に生成します。地上の昼夜BGMは、このプロジェクト用に制作した各5分のMP3を同梱します。ゲーム実行時のネットワーク接続・追加コーデックは不要です。

## 効果音

足音・ジャンプ・着地・遊泳・灯籠、着水・水面へ出る音・控えめな水中音は従来の音源と音量を維持しています。波・風・高所の風の音源はありません。

石の足音は3種類を歩行距離約2.1ごとに交互に再生し、音程を少し変化させます。空中・飛行・水中・静止中に足音は鳴りません。ジャンプは短い上昇音、着地は低い衝撃音で、実際の物理イベントに合わせて一度だけ鳴ります。水中を動くと柔らかな水音を加えます。
歩行音は前回の半分（初期実装の8分の1）です。ジャンプ音・着地音は前回の音量（初期実装の4分の1）を維持し、着地音は落下速度に応じて調整した後に0.25倍します。

灯籠は880 Hzと1320 Hzの小さな鐘です。描画と同じ点灯スケジュールを使い、24単位以内で距離減衰とステレオ定位を適用します。既に点灯している灯籠に近づいても鳴りません。密集時の最短間隔は0.35秒、消灯は無音です。

着水は1.6秒のノイズの広がりと低い響きを重ねた「ざばーん」という音です。`Explorer` が水へ入ったときの速度を物理サブステップ内で記録し、音量を調整します。着水後の各フレームで繰り返し鳴りません。

水面へ出る音は0.75秒の短い水音です。足元の遊泳判定ではなく視点の高さで判定し、顔が海面下0.08より深く入った後、海面上0.08より上へ出たときに一度だけ鳴ります。この幅で水面付近の連打を防ぎます。自然浮上でもSpaceによる浮上でも鳴ります。テレポートや飛行による移動では鳴りません。

## 水中の環境音

12秒のループです。低域を残したノイズ、47/71 Hzの低い響き、小さな泡を重ね、水中のこもった感覚を作ります。ノイズのフィルター状態も周期境界でつながるようにします。視点が海面下に入るとフェードインし、水上ではフェードアウトします。ループの最大音量を以前の0.65から0.30へ下げ、音源自体のノイズと低音も抑えています。

高度による環境音はありません。水中の環境音とBGMの水中での音量低下は変更していません。

## 地上のBGM

`CAERO/Music/day.mp3` は **Drifting Corridors**（明るく開いた和音・柔らかい鍵盤・控えめな高音）、`night.mp3` は **The Unlit Courtyard**（低い短調の和音・まばらな鍵盤・長い余韻）です。それぞれ300秒、44,100 Hz / ステレオ / 192 kbps。9つのゆっくりした和声場面で展開する新しい曲で、以前の32秒の音を繰り返したものではありません。

先頭1.5秒と終端2秒を無音にし、冒頭は12秒かけて立ち上がり、終盤は22秒かけて減衰します。残響にも最後のフェードを適用します。MP3デコード後も最初・最後の各1秒が無音であることを検証します。終端と先頭の波形を無理につなげず、無音を挟んでループします。昼夜の長さが将来変わっても曲を再生し続けられます。

2本を同時刻からループ再生し、従来と同じ昼夜の明るさから求めた等電力の音量比でクロスフェードします。水中ではBGMを下げます。Nで時間倍率を変えても音程・演奏速度は変わりません。

音量は急に切り替えず指数補間し、開始時もフェードインします。ウィンドウが非アクティブな間は効果音を止め、環境音・BGMをフェードアウトします。Mも全音声に適用します。設定は次の起動時に通常状態へ戻ります。

## 実装と寿命

`AudioDirector` が9個の効果音と3個のストリーム（水中・昼BGM・夜BGM）を所有します。水中WAVだけを固定メモリから読み、BGMは `LoadMusicStream` で同梱MP3から読みます。全ループに `Looping=true` を設定し、毎フレーム `UpdateMusicStream` を呼びます。終了時はストリーム・水中の固定メモリ・効果音・デバイスの順に解放します。音声APIはメインスレッドから呼び、管理コードの音声コールバックは使いません。生成区画ごとの音源は蓄積せず、灯籠の履歴も近傍だけを保持します。

通常プレイでは音声を有効にします。音声デバイスを初期化できない場合は音声を解放し、HUDに `AUDIO UNAVAILABLE` を表示して探索を続けます。`--no-audio` でも初期化を省略できます。`Music/day.mp3` と `Music/night.mp3` はビルド・publish時に自動コピーされるので、配布時は `Music/` フォルダーも含めてください。

## 音源の書き出しと確認

CAERO5フォルダーから:

```powershell
dotnet run --project CAERO -c Debug -- --audio-test
dotnet run --no-build --project CAERO -c Debug -- --audio-smoke-test
```

`--audio-test` はデバイスを使わず、10個の合成音源と2本のMP3が揃うことを確認します。MP3を実際にデコードし、約300秒の長さ・ステレオ・有限値・音量の余裕・先頭/終端の無音を検査します。従来の水中ミックス・水中ループの境界・効果音の端のフェードも検査します。実際の物理移動でジャンプ・着地の単発イベント、dt=0.01/0.05/0.1ごとの高速着水・自然浮上・再潜水と浮上、テレポート・飛行時の誤発音防止を検証します。

10個の合成音源と、水の3音だけを抜き出した18秒の `caero4-water-preview.wav` をDebugの `SaveData/Audio/` に書き出します。試聴用ミックスは、無音→着水→水中→水面へ出る音→無音、の順です。生成ファイルはGit管理対象外です。

`--audio-smoke-test` は上の検証に加え、実デバイスで34秒再生します。3本のストリームと全9効果音、ミュートと復帰、GC後のメモリ保持を確認し、再生中のMP3を終端2秒前へシークして実際のループ越境・再開も検証します。通常プレイのセーブは変更しません。

## 曲の再制作

`Tools/compose_ambient.py` が譜面・音色・残響・フェードとMP3エンコード処理を保持しています。Python + numpy と、引数で指定したLAME共有ライブラリが必要です。これらは制作時だけ使用し、ゲームには不要です。例:

```powershell
python Tools/compose_ambient.py --lame path/to/libmp3lame64.dll
```

曲名・長さ・音量・SHA-256は `CAERO/Music/manifest.json` に記録します。無圧縮マスターWAVはGit管理外の `SaveData/Audio/Composition/` に保存します。
