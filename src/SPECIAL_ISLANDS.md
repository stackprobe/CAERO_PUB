# 特別な島の追加配置

通常の島生成の最後に、外部JSONの定義から碑文・人物・能力アイテム・脱出の碑石を追加します。通常の地形・建物・灯籠・島番号・ワープ装置の乱数列や、通常の人物の生成結果は変更しません。

## 設定ファイル

ソースは `CAERO/Content/special-islands.ja.json` です。ビルド・発行時に実行ファイルの隣の `Content/special-islands.ja.json` へコピーされます。配布後もこのJSONを編集でき、反映にはゲームの再起動が必要です。再ビルドする場合はソース側も編集してください。

`version` は現在 `1` です。設定は起動時に一度読み込み、島生成のワーカーと共有します。形式不正・未知の項目・重複IDなどは設定ファイル名付きのエラーになります。

| 項目 | 内容 |
| --- | --- |
| `id` | 全体で一意な、変更しない識別子。取得済みの記録にも使います。 |
| `island` | 島番号の10進文字列。島座標やシードではありません。 |
| `kind` | `inscription`（碑文）、`resident`（人物）、`item`、`exit`。 |
| `name` | Eの案内や本文画面の見出し。 |
| `surface` | `towerInterior`（壁付き階段塔の1F）、`hallRoof`（壁のない広間の2F／屋上）、`ground`（島の1F屋外）。 |
| `position` | `[x, 0, z]`。島の回転前の建物に対する座標。Yは基準床からの高さで、現在は浮かせず置くため0のみ対応します。屋上の床高はシードで生成された広間の高さを使います。 |
| `yawDegrees` | 回転前の向き。0は+Zを正面とし、90は+Xです。島の回転にも追従します。 |
| `searchRadius` | 指定点に置けないときに安全な床を探す半径。0は指定点のみ。近い整数オフセットから固定順で探すため再訪時も同じです。 |
| `color` | 6桁のRGB（`#`なし）。碑文の上帯・刻み・操作案内やアイテムの色。赤・青・紫の区別を設定しています。 |
| `pose` | 人物の `standing` または `sitting`。特別な人物はその場に留まります。 |
| `huddled` | `sitting` の人物で `true` にすると、頭を下げ、膝を抱えるようにうずくまる姿勢になります。省略時は `false`。 |
| `minResidentDistance` | 同じ階の他の人物・巡回経路から確保する距離（0～20）。省略時は通常の接触回避のみ。 |
| `age` / `gender` | 人物の `child` / `adult` / `elder` と、`male` / `female`。 |
| `effect` | アイテムの `dash` / `jump` / `flight`。その他は `none`。 |
| `pages` | 本文を文字列の配列で指定します。1要素が1ページで、ページ内の改行は `\n`。自動ページ分割は行いません。空の配列・空白のみのページは不可、全ページ合計20,000文字までです。画面に収まるよう1ページ28文字×3行程度を目安にしてください。脱出の碑石では全ページを改行で連結し、触れるかどうかの確認文として表示します。 |

`dialogue.ja.json` と同じように、表示したい区切りでページを記述します。ページ数は自由です。既存の `text` は `pages` に移行してください。

```json
"pages": [
  "最初のページです。\nページ内で改行できます。",
  "次のページです。"
]
```

配置は実際の床・頭上・壁・他の追加物・通常の人物の巡回経路・既存の歩行確認経路を確認します。探索しても置けなければ、島番号・シード・対象ID・拒否理由を含むエラーを出します。配置を黙って省略しません。シードによる周囲の違いで指定点から少し移動する場合があります。

配置座標の目安は、階段塔の室内が `13.5 < x < 30.5, 14 < z < 32`、広間の屋上が `-27 < x < 18, -33 < z < -11`、屋外が島中心の±32以内です。塔の左右の階段・屋上の縁・灯籠などはその範囲内でも避けます。塔の奥の踊り場の下も、頭上の余裕を確認して室内の配置先として使えます。

個別の場所・眺める方向の指定がない旅人23人は、同じ座標・0度の向きを使い回さず、島ごとに異なる座標と向きを設定しています。塔内・広間の屋上・屋外という配置先と立つ／座る姿勢は維持し、その面の中で分散させています。島1の島3を眺める人物・塔屋上の隅に座る人物、島641の壁にもたれる人物は専用の配置を維持しています。

特別な人物32人の白い服には、裾の少し上に淡い灰緑色の細い二重ラインがあります。遠目には通常の白い服になじみ、近づくと共通の織り模様に気づく程度の特徴です。立つ姿勢・座る姿勢の両方で布の形に沿わせ、年齢・性別による体格にも追従します。通常生成の人物には付きません。

碑文も、個別の位置指定がある島90263の3基を除く11基の座標・向きを分散させています。赤い碑文は塔内、青い碑文は広間の屋上という配置先は維持しています。全14基の石と台座は濃い黒灰色にして、淡い背景から見分けやすくしています。石自体は発光させず、赤・青・紫の文字だけが控えめに発光します。壁による遮蔽や距離による霧は通常どおり適用します。

正面の横棒は廃止し、見出しと長さの異なる12行の架空文字をテクスチャで貼っています。`InscriptionSurface.CreateTexture()` が起動時に共通の文字マスクを生成し、回転前の碑面に合わせたUVで表示します。角張った20種類の字形、単語の間隔、微かな摩耗を組み合わせています。石の正面そのものへ描くため、重ねた板のちらつきはありません。Eで読む日本語の本文は従来どおりJSONの `pages` を使います。

島3の青い碑文と人物は屋上の階段から離して置き、碑文は上り切った位置へ正面を向けています。島1の青い碑文は灯籠から離れる壁側へ寄せています。`--capture-special=1` / `3` の `roof-stair-view` 画像で階段上からの見え方を確認できます。

島2の赤い碑文は塔の室内の奥の隅 `[14.2, 0, 31.8]` に寄せ、135度で部屋の内側へ向けています。

島7の赤い碑文は入口から見た部屋の奥 `[22, 0, 29]` に移し、180度で入口側を向けています。`--capture-special=7` の `entrance` 画像で入口からの見え方を確認できます。

島227の赤い碑文は、固定シード1701の東西の入口を避けて塔内奥の中央 `[22, 0, 29]` に置き、180度で室内の入口側を向けています。屋外の旅人2人は `[-18, 0, 12]`・120度と `[7, 0, 23]`・270度に配置し、階段や塔の壁から離れて広場側から話しかけられます。`--capture-special=227` の `west-entrance`・`interior`・`surroundings` 画像で周囲との位置関係を確認できます。

島1601の赤い碑文は灯籠と反対側の壁の中央 `[30, 0, 22]` に寄せ、270度で部屋の内側を向けています。`--capture-special=1601` の `wall-view` 画像で正面からの配置を確認できます。

## 収録内容

島1169587の「脱出の碑石」は、最初の踊り場（高さ6）から階段の間を奥の壁まで延ばした廊下の突き当たりにある専用オブジェクトです。
`surface: "towerLanding"`、`landing: 1`、`position: [22, 0, 12.2]` で配置し、踊り場側を向いています。
追加廊下はこの島だけに設置し、幅4（X=20～24）、Z=11～30の床で既存の踊り場につなげています。他の島の塔は変更しません。
円形の台座・浮いた結晶・発光する環を備え、淡い青白い光が6秒周期でゆっくり強弱し、近くの床もほのかに照らします。
昼夜を問わず光り、既存の階段の通行スペースを残しています。Eで調べると、触れるかどうかを選択できます。

島90263の赤い碑文は、塔の入口から入った正面奥の中央に、入口を向けて配置しています。
紫の碑文2基は、下から2つ目と3つ目の踊り場に配置しています。

`position` のYは他の面と同じく0で、実際の高さは踊り場から決まります。碑文は階段の通行経路を避け、踊り場から読める向きにしています。

島641で双子の候補を百三十組調べた話をする旅人（`island-641-05`）は、広間の屋上の壁にもたれて座ります。

足元・身体の収まりに加え、腰と肩の背後に壁があること、正面から話しかけられることを確認します。

島1の壁付き階段塔の屋上には、南東の隅に座る「屋上に座る人」も追加しています。

会話に任意の `choice` を付けると、`pages` の最後のページを読み終えたところで「はい／いいえ」を選べます。
矢印キーまたはWASDで選択し、E・Space・Enterで決定、Escで会話を閉じます。
選択後は対応する配列だけを表示し、空の配列ならその場で会話を終えます。分岐先も含めて本文は合計20,000文字までです。
通常の `dialogue.ja.json` の会話でも同じ `choice` を使用できます。

```json
"pages": ["……碑文の謎は、わかったかい？"],
"choice": {
  "yesPages": ["そう。\n……なら、いいんだ。"],
  "noPages": ["……教えてあげる。\n答えだけね。"]
}
```

## 操作・能力・保存

近づいて対象を見て **E** で、会話・碑文閲覧・アイテム取得・脱出の確認を行います。壁越しや背後の対象には反応しません。本文表示中は移動を止め、E／Spaceで全文表示・次のページ、Escで閉じます。碑文の本文は読める日本語で画面に表示し、3Dの碑石には架空文字のテクスチャを貼っています。

アイテムは台の上の液体薬瓶です。ダッシュ強化は明るい青、ジャンプ強化は明るい赤、飛行能力は明るい緑です。Eで「青い薬がある。\n飲んでみますか？」を表示し、赤は「赤い薬」、緑は「緑の薬」に置き換えます。はいで初めて取得・能力反映・取得音・即時保存を行い、既存の `pages` の取得後メッセージを表示します。いいえ・Escでは取得せず、薬瓶は残ります。一度飲んだ瓶だけが消えて台は残り、再取得できません。現在の効果量はJSONの共通設定で編集できます。

- `dashBonusPerItem: 3`：Shift時の歩行・飛行速度13、遊泳速度9に、1個につき3を加算します。通常移動はそのままです。2個で歩行・飛行19、遊泳15になります。
- `jumpBonusPerItem: 0.12`：1個につきジャンプ初速の倍率を0.12加算します。2個で初速1.24倍、跳躍高度は約1.54倍です。
- `flight`：初期状態では飛行できず、この薬を取得するとジャンプ中のFで飛行を開始できます。飛行中は視線の方向へ常に前進し、マウスで進路を変えます。WASD・Space・Cで停止・後退・上下移動はできません。Fで飛行を解除します。Fによる開始時は専用の上昇音、解除時は既存の終了音が鳴り、それぞれ独立した音量設定があります。壁・床・天井に当たったときの解除音は従来の約1.67倍の再生音量です。

取得IDは既存の `generated-view.json` に、ワールドシード・位置と一緒に保存します。10秒ごと・取得時・脱出時・ポーズ時・タイトルへ戻る時・終了時に自動保存します。手動保存キーはなく、タイトルの「コンテニュー」で位置と能力を復元します。取得済みの薬瓶は再取得できず、再訪・再起動しても台だけが残ります。旧セーブには取得記録がないため、能力未取得で開始します。ワープ・島の解放と再生成では取得状態は失いません。

クリア実績は、脱出の碑石の確認で「はい」を選んだ直後の保存時に `achievements.json` へ記録します。通常セーブとは独立し、新規開始・通常セーブの削除後も保持します。確認を閉じる・「いいえ」を選ぶだけでは獲得しません。タイトル左下のトロフィーとホバー時の説明で確認でき、獲得時の演出はありません。

`id`を変えると別のアイテムとして扱われます。取得済みIDの効果種別や共通の強化量を編集すると、読み込み時にその設定で能力を再計算します。設定から削除されたIDは無視します。

脱出の碑石をEで調べると「碑石は輝いている。\n触れてみますか？」と、はい／いいえを表示します。いいえ・Escは探索へ戻ります。はいを選ぶと約2秒で白へフェードし、白地に「あなたは、脱出した。」が浮かび上がります。5秒目から約3秒かけて `Content/ending.png` へ移り、画像が出きってから3秒待って「タイトルに戻る」ボタンを表示します。ボタンはマウス・Enter・Spaceで操作でき、表示前の連打や押しっぱなしで演出をスキップできません。演出中はポーズ・移動を止め、マウスカーソルを表示します。

はいを選んだ時点で、ゴール時の取得アイテムを保持し、碑石の2.19単位手前から碑石を向く視点を保存します。保存上は脱出前の状態にするため、タイトルへ戻る・演出中に終了する、どちらの場合もコンテニューで碑石の前から探索を再開し、もう一度調べられます。セーブデータは削除しません。

## 検証

```powershell
dotnet run --project CAERO -c Release -- --special-test
dotnet run --project CAERO -c Release -- --ending-test
dotnet run --project CAERO -c Release -- --capture-ending
dotnet run --project CAERO -c Release -- --capture-special=1
dotnet run --project CAERO -c Release -- --capture-special=57
dotnet run --project CAERO -c Release -- --capture-special=90263
dotnet run --project CAERO -c Release -- --capture-special=1169587
```

`--special-test` は8シード・17島で全52件の配置・再現性・通常生成との比較を行います。Eの到達、壁越し／背後の拒否、長文ページ、座る指定、二重取得、能力の実際の移動・跳躍への反映、取得状態のセーブ往復・再訪・脱出を検証します。`--movement-test` にも含まれます。

`--capture-special=島番号` は実際のOpenGLでその島の碑石・アイテム・人物・日本語本文を撮影し、取得後の表示除外も確認します。通常のセーブは読み書きしません。画像は既存の撮影と同じ `Captures/` へ出力します。

2026-10-22にDebug／Releaseビルド、352件の配置検証、426本の経路歩行を含む全体移動テストを通過しました。島1・57・90263・1169587の実描画で、碑文・会話・取得後の表示除外・エンディングを確認しています。碑文14件と会話24件の本文は、元のMarkdownと全件照合済みです。

薬瓶への改修後も全体移動テストを通過し、島13・31・57で青／赤／緑の瓶と取得後の台の残存を実描画で確認しました。`--flight-test` はジャンプ中のみの飛行開始・無入力時の前進・視線での操縦・解除を検証します。`--audio-smoke-test` は飲み干す音と大きくした飛行衝突音を含む13種類のSEを実際の音声デバイスで再生します。
