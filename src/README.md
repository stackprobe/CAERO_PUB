# CAERO5 — The wandering citadels

海上の島・城塞・回廊を、移動に合わせて生成する C# / raylib の探索デモです。
CAERO4の空間と音声を引き継ぎ、ここに閉じ込められた白いローブの人々と会話できます。
CAERO3 の固定マップは使用しません。現在地の周辺を生成し、遠い場所は描画モデル・当たり判定・灯籠ごと解放します。

## 白いローブの人々

- 最初の島に3人、ほかの島には0〜2人をまばらに、子供・大人・老人、男性・女性を配置します。素朴な白い長衣、裸足、俯いた顔で、疲れた様子を表現しています。
- ゆっくり力なく歩く人、しゃがんで頭を抱える人、横たわってわずかに呼吸する人がいます。
- 近くの人の方を向くと会話の案内を表示します。**E**で話しかけ、**E / Space**で文章を全文表示・次のページへ進み、**Esc**で閉じます。会話中はプレイヤーの移動を止め、相手も歩みを止めます。
- 従来の8種類・各3ページ、合計24ページの日本語会話があります。出口の見えない世界での疲れや、失った記憶、帰る場所への思いを語ります。
- セリフは [CAERO/Content/dialogue.ja.json](CAERO/Content/dialogue.ja.json) に外部ファイル化しています。編集後に再ビルド・再起動すると反映され、配布版でも実行ファイルの隣の`Content/dialogue.ja.json`を編集できます。
- 人物は床と移動経路を確認した場所にだけ配置します。遠い島を解放すると人々も解放し、戻ると同じ人物を再配置します。

会話はテキスト表示です。日本語フォントはWindowsに入っている游ゴシック・メイリオ・MSゴシックのいずれかを読み込みます。モデルやフォントの追加ダウンロードは不要です。詳しくは [PEOPLE.md](PEOPLE.md) を参照してください。

## 深海の巨大魚

水底近くを全長約25の巨大魚がゆっくり泳いでいます。体は暗く、目だけが鈍く光ります。
魚は普段は海底すれすれを泳ぎます。潜水開始から5秒でこちらの海域へゆっくり移動し、15秒で足元付近へ近づき、25秒で襲いかかります。水中で魚の中心から28単位未満へ近づくと、潜水時間に関係なく襲われます。襲撃時だけ主人公の高さへ向かってきます。浮上すると警戒は解除されます。
入水するタイミングで、その周辺の海底へ魚を1体配置し直します。水面で揺れている間や潜水中に何度も出現し直すことはありません。配置に失敗した場合も再試行します。
海中は探索対象ではなく、深く暗い危険な場所として描きます。海底は底の形が見えないほど暗くし、水中の映像には深さによらず強いぼかしを掛けます。水面と水中が同時に見える場合も水中側だけをぼかします。
大きく開いた口に捕まると、短い暗転を挟んで最初の島へ戻ります。位置・落下速度・遊泳状態も初期化します。
水面へ顔を出すと追跡が終わり、陸上には襲ってきません。詳しい仕様と検証は [PREDATOR.md](PREDATOR.md) を参照してください。

## 自動生成

- 全ての島に床面と同じ高さの方位盤を埋め込みます。島シードに基づいて、建物・灯籠・雑草と重ならず歩いて近づける場所を選び、オブジェも方位盤を避けます。N=北（−Z）、E=東（+X）、S=南（+Z）、W=西（−X）で、太陽は東から昇ります。島の建物が回転しても方位は変わりません。
- 全ての島の外壁に、固有番号の看板を埋め込みます。塔の四方の外壁から島シードに基づくランダムな位置を選び、入口や柱を避け、歩いて近づける場所に設置します。暗い縁・金色の内枠・四隅の留め具・「ISLAND」の見出しを備え、オブジェも看板の前を避けます。最初の島が1、東が2、北東が3、北が4、北西が5と続くウラムの螺旋です。番号はワールドシードに依存せず、64bitの島座標全域で正確に計算します。長い番号は10桁ごとに左から右、上から下へ折り返します。
- 通常はクリーム色の地に暗い数字を表示します。番号が素数と確定した看板は白地・赤い数字へ変わります。1は素数ではありません。判定は全ての島で共有する1フレーム合計0.35ms目安・最大64工程の枠で少しずつ進め、色の変更時にもメッシュの再生成・再転送は行いません。大きな番号は判定に時間がかかる場合がありますが、未確定の間は通常色で表示します。
- 方位盤・プレートは床・壁の面を切り抜いて同一平面に組み込むため、段差や表面のちらつきはありません。検証は `dotnet run --project CAERO -- --wayfinding-test`、描画確認は `--capture-wayfinding`（任意で `--identity-cell=X,Z`）を使用できます。

- 192 単位ごとのエリアに、岩の島、中庭、アーチの大広間、屋上へ続く階段、折り返し階段を備えた塔、海から上陸する階段を生成します。
- 島の輪郭、石材の色、大広間の高さ、塔の階数、建築全体の向きがシードとエリア座標で決まります。共通の建築部品と配置ルールを使う方式です。
- 壁で囲まれた階段塔の入口は、島シードに基づいて四方から1〜4か所を選びます。どの入口からも階段へ歩いて進め、再訪しても同じ位置・数になります。島番号の看板は入口を避けます。
- 島の四隅の高さ2のブロックには、内側に高さ1の踏み台があります。通常のジャンプで踏み台からブロックの上へ登れます。
- 東西南北の地上の橋は高さと端点が一致し、隣の島まで歩いて移動できます。既存の建物と新しい階段塔の主経路はジャンプ・飛行なしで往復できます。
- スタート区画の形状を維持し、原点から離れるほど5段階で建築が複雑になります。階段塔の高さは72〜288、周囲の高層建築や上空の柱はさらに高くなります。
- 外周に向かって、骨組みの塔、壁帯のある高層建築、張り出したテラス、段状の高層群、屋上の横断橋、区画間の空中廊下、浮遊するビル・柱・梁が重なります。浮遊建築は意図した構造物で、小物の足場チェックは維持しています。
- 空中廊下も隣接する区画と高さを合わせます。高層の階段塔から既存の屋上、高所の通路、浮遊する中庭へ移動できます。
- 起動時は周囲 5×5 エリアを準備します。以降は一つのバックグラウンドジョブで先のエリアを計算し、毎フレーム最大一つの完成エリアを描画へ追加します。
- 保持範囲は現在地から最大 3 エリア先まで、最大 49 エリアです。歩いた距離に応じて全マップをメモリへ蓄積することはありません。
- 解放した場所へ戻ると、同じシードから同じ形・通路を再生成します。建物の破壊や配置変更の永続化はありません。
- 灯籠の配置は島ごとに変わります。台座の足場を確認し、屋上の歩行経路を避けて配置します。
- 原点から5島分以上の直線距離で、壁材20種類・横へ広がる建築20種類の変化が始まります。距離5〜35にかけて、壁材の色や模様、張り出しの大きさと組み合わせ数、雑草の密度と高さが徐々に強まり、35以上は最大の変化幅を維持します。
- 壁材は煉瓦・地層・コンクリートパネル・切石・玄武岩・粘板岩・大理石・砂岩・タイル・縦溝・長煉瓦・苔石・菱形・漆喰・緑青・木目・リブ・乱積み石・有孔板・山形模様の20系統。縮尺・色味も島ごとに変わります。
- 横広がりは回廊・段状テラス・鋸歯状・指状・中庭・二股・ずれた部屋・ドーム・棚・二重回廊・扇・段状ピラミッド・円形後陣・格子・控え壁・パーゴラ・垂れ壁・十字館・円筒群・冠付き広間の20種類。近くでは小さな1種類、遠方では異なる4〜5種類を組み合わせ、張り出しは最大約34単位になります。
- 雑草はスタート島を含む全島に生え、群生場所に加えて島全体の量も独立した乱数で決めます。全島で以前の生成方式（12〜35群生候補・各3〜9株）による島ごとの量を最低限確保し、不足する島だけ補います。雑草が多い島の量と配置は維持し、遠方ほど群生数・株数・背丈の変化幅が増します。
- 全島に地上のオブジェを1つずつ置きます。通常の島の形状は20種類です。長い腕の像、空洞の目、積層像、三叉、螺旋階段、鳥、鳥籠、砂時計、鍵、環のある惑星などがあり、色も20種類。種類・色・位置・向きを島のシードで決めるため、再訪すると同じ姿になります。スタート島だけは青灰色の専用記念碑で、少し大きな台座と支柱に交差する二重の環と多面体を組み合わせた複雑な形です。
- オブジェは回転後の全体の範囲で壁・梁・階段・灯籠との重なりを確認します。重なる場合は近くへずらし、別の場所も探します。足場や歩行経路も確認し、安全な場所がない場合は配置しません。
- X/Z各±30,000の探索制限はありません。島を移るたびに現在の島の中心をローカル座標(0,0)へ戻し、遠方でも描画・物理の座標を小さく保ちます。島の住所は符号付き64bit整数で管理します。HUDは島の住所と島内のローカル座標を表示します。

島専用のシードは、整数の島座標を `x:z` と表記したASCIIバイト列のSHA-512先頭128bitから作ります。ワールドシードと用途別の固定値も混ぜ、自前のxor128（32bit×4の状態、シフト11/19/8）で生成します。マップ生成は `System.Random` に依存せず、同じシード・座標から同じ島を再生成します。ワールドシードの設定値自体は従来どおり32bit整数です。

シードの初期値は `1701` です。別の世界を試す場合:

```powershell
dotnet run --project CAERO -c Debug -- --seed=48291
```

シードを指定しなければ、保存されたシードと視点を復元します。指定したシードがセーブと異なる場合は、その世界の最初の島から開始します。

## 実行

Windows 10/11 x64、OpenGL 3.3 以上、.NET 8 SDK が必要です。
Visual Studio 2022 17.8 以上では「.NET デスクトップ開発」を用意して `CAERO.sln` を開き、F5 で実行してください。

CAERO5 フォルダーから:

```powershell
dotnet run --project CAERO -c Debug
```

依存: Raylib-cs 7.0.2（ネイティブ raylib 5.5）。外部の画像素材は不要です。

## 操作

| キー | 動作 |
| --- | --- |
| WASD / マウス | 移動 / 視点 |
| Shift | 高速移動 |
| Space | ジャンプ / 遊泳・飛行中に上昇 |
| Ctrl | 通常の10倍速で移動（歩行・飛行・遊泳、Shift同時押しでも10倍） |
| C | 潜水 / 飛行中に下降 |
| F | 歩行・飛行切り替え |
| E | 近くの人に話しかける / 会話を進める |
| N | 昼夜の進行速度を ×1 → ×10 → ×1 … と切り替え |
| M | 効果音・水中音・BGMをまとめてミュート / 解除 |
| 1 | 最初の島へ戻る |
| F5 / F9 | 視点とシードの保存 / 視点の読み込み |
| H | 操作ガイド |
| Esc / 左クリック | マウス捕捉の切り替え / 捕捉再開 |
| Alt+Enter | ウィンドウ・枠なし全画面切り替え |

海では泳いで潜水でき、各島の水面下から始まる階段で上陸できます。
着水時は落下速度を引き継ぎ、勢いが強いほど深く沈みます。水の抵抗で減速した後は、入力がなくても浮力でゆっくり水面へ戻ります。Spaceで浮上、Cで潜水できます。Ctrl押下中は通常の10倍速で移動します。Shiftの高速移動は従来どおりで、Ctrlと併用した場合は10倍速を優先します。
ジャンプは平地で約1.5の高さまで上昇します（強化前の約1.5倍）。橋の手すりへは助走をつけて飛び乗れます。高い屋上へは階段を使って移動します。Spaceを押した瞬間だけ跳び、押し続けても壁を登ることはありません。
起動時は夜明けから始まり、昼5分・夜5分で自動的に繰り返します。太陽と月は10分で一周し、地平線でフェードイン・アウトします。明け方と夕暮れには約36秒かけて周囲の明るさが変わります。投影する影はありません。
灯籠は夕暮れ・夜明けに約28秒の幅でまばらに点灯・消灯し、それぞれ3〜9秒かけて光が変わります。順序は毎晩ランダムです。Nで時間の進行を通常速度と10倍速に切り替えます。10倍速では昼・夜が各30秒となり、天体・明るさ・灯籠も同じ速度で変化します。現在の速度は操作ガイドに表示します。
終了はウィンドウを閉じるか Alt+F4 です。終了時にも視点とシードを保存します。
1 / F9 の明示的な移動では、移動先の周辺を同期的に準備するため短い待ちが発生する場合があります。

## 音

効果音と水中の環境音は従来どおり、起動時に波形・ノイズから合成します。地上のBGMは同梱するオリジナルのMP3を再生します。

- 水へ飛び込んだときの「ざばーん」という音。落下の勢いで音量が変わります。
- 水中から顔が水面へ出たときの短い水音。
- 水中にいる間だけ聞こえる、控えめな低い響きと泡を重ねた環境音。水面で滑らかにフェードします。
- 石の足音3種類、ジャンプ、着地、遊泳時の水音。
- 近くの灯籠が点灯し始めたときの小さな鐘の音。
- 昼夜に合わせて滑らかに切り替わるアンビエントBGM。昼用 `Music/day.mp3` と夜用 `Music/night.mp3` は各5分で、先頭と終端は無音です。昼夜が長くなった場合もループ再生します。水中での音量低下は維持します。

波・風・高所の風の音はありません。Nの10倍速は音程や演奏速度を変えません。ゲームが非アクティブになると音量を下げ、戻ると徐々に復帰します。Mでミュートできます。音声デバイスがない場合も探索を続けられます。
`--no-audio` は音声の初期化を省略する起動オプションです。撮影と既存の自己テストでは音声を初期化しません。音の構成と確認方法は [AUDIO.md](AUDIO.md) を参照してください。

## 保存と配布

- Debug: `CAERO.sln` のあるフォルダーの `SaveData/`
- Release: 実行ファイルと同じフォルダー

保存ファイルは `generated-view.json` です。シード、生成仕様のバージョン、位置・視点・飛行モードを保存します。
コピー元の `view.json` は使用しません。F9 では現在と同じシードのセーブのみ復元します。
現在の生成仕様はバージョン3です。旧バージョン1/2のセーブはワールドシードを引き継ぎ、新しいスタート島から再開します（島の形が変わるため旧位置は復元しません）。それ以外の未対応バージョンは読み込みません。
座標形式はバージョン1で、64bitの島座標と島内の位置を分けて保存します。生成仕様3の旧セーブは従来の絶対座標を変換し、元の位置・視線・飛行状態を維持します。今回の座標変更による開始地点へのリセットはありません。

```powershell
dotnet publish CAERO/CAERO.csproj -c Release -r win-x64 --self-contained true -o out/win-x64
```

`out/win-x64` 全体を配布してください。シェーダーとネイティブ DLL が必要です。
