# CAERO5 の人々と会話

白い質素なローブを着た老若男女が、島の中庭にいます。外部モデルを使わず、共有する5つのメッシュから衣装・頭・手足・髪を描きます。長い袖と裾は不透明な薄い布として扱い、石材の目地は適用しません。世界と同じ霧・昼夜・灯籠の光に馴染ませ、影は追加しません。

## 姿と動き

8つの人物像を用意しています。白髪の老人、痩せた女性、横たわる若者、うなだれた老女、小さな少女、俯いた少年、疲れた男、身を横たえた女性です。背丈・体格・髪・顔色を変え、下がった頭、閉じ気味の目、垂れた腕、小さな呼吸の動きを付けています。

歩く人は毎秒0.32単位で、検証済みの2.5単位の経路を往復します。会話中は相手の動きを止め、終了すると再開します。しゃがむ人は頭を抱え、倒れている人も生きていて話せます。人々は経路を塞ぐ固い障害物にはしていません。

## 配置と所有権

最初の島に3人、その他の島に0〜2人です。中庭と大広間に配置候補を分散し、歩行経路を含めて互いに15単位以上離します。ワールドシードと区画座標から人物像・向き・配置候補を安定して決め、建築を生成する乱数列は消費しません。元のマップの頂点や通路は変わりません。

配置時に、体全体の範囲と歩行経路を0.25単位刻みで調べます。中心・辺・四隅に同じ高さの床があり、壁や天井にぶつからない候補だけ採用します。横たわる姿には広い範囲を確保します。島の解放と同時に人物も管理対象から外れます。再訪時には同じ人物・開始位置から再生成します。会話履歴や歩行途中の位置はセーブしません。

## 操作と会話

3.4単位以内で正面にいる、壁に遮られていない最も近い人を選びます。プロンプトが出ているときにEで開始します。

- E / Space: 文字が出ている途中なら全文表示、表示済みなら次のページへ。
- Esc: 会話を閉じる。マウスの捕捉は保ちます。その後もう一度Escで通常のマウス解放になります。
- 最終ページの次へ進むと会話を閉じます。会話中は移動・視点・ジャンプを止め、Spaceがジャンプ音を発生させることも防ぎます。
- 1 / F9による明示的な移動や、相手の区画の解放時には会話を閉じます。

従来の8種類・各3ページ、合計24ページの日本語会話があります。出口の見えない世界での疲れや、失った記憶、帰る場所への思いを語ります。追加した992会話は取り下げ、元の会話本文に戻しています。音声読み上げや選択肢、クエストはありません。

## 外部会話ファイルの編集

開発時の原稿は [`CAERO/Content/dialogue.ja.json`](CAERO/Content/dialogue.ja.json)（UTF-8）です。ビルド・publish時に実行ファイルの隣の`Content/dialogue.ja.json`へコピーします。開発時は原稿を編集して再ビルド、配布版は同梱JSONを編集し、ゲームを再起動してください。起動中の自動再読み込みはありません。

ファイル全体は`version: 1`、`language: "ja"`、`conversations`配列で構成します。配列内の1会話の例:

```json
{
  "id": 0,
  "name": "白髪の老人",
  "age": "elder",
  "gender": "male",
  "pose": "crouching",
  "theme": "原初の声",
  "pages": [
    "出口を探して、橋をいくつ渡っただろう。\n向こうにも同じ空と、同じ石があるだけだった。",
    "腹も減らない。眠くもならない。\n休んでも、この疲れだけは消えてくれないんだ。",
    "ここへ来る前のことは何も覚えていない。\n帰りたいのに、帰る場所さえ思い出せない。"
  ]
}
```

- セリフの編集は`pages`、表示する呼称の編集は`name`です。`pages`は空でない3要素。改行はJSON文字列内の`\n`で指定でき、画面幅による自動折り返しもあります。現行原稿は640px幅でも全ページ2行以内です。
- `age`は`child` / `adult` / `elder`、`gender`は`male` / `female`、`pose`は`walking` / `crouching` / `collapsed`。会話に対応する人物の外見・姿勢にも反映するため、文体や呼称と合わせてください。
- `id`は配列の順番と一致する0始まりの連番です。再訪時にも同じ会話を選ぶため、既存IDを入れ替えず、追加時は末尾へ連番で追加します。最初の島の3人はID 0・5・7を使います。
- `theme`は編集・点検用の主題で、ゲーム画面には表示しません。ファイルは初回に一度だけ読み込んで共有し、島の生成ごとのファイルアクセスは行いません。
- ファイルがない場合やJSONの構文・ID・人物情報・ページ数が不正な場合は、黙って別の会話へ置き換えず、原因が分かるエラーにします。全く同じ3ページの会話の重複も検出します。

## 日本語表示と検証

Windowsの既存フォントを読み込み、会話で使用する文字だけをアトラスにします。TTCコレクションの最初の書体をメモリ上で取り出してraylibへ渡します。フォントファイルはプロジェクトや配布物にコピーしません。ウィンドウ幅に合わせて文字サイズと折り返しを調整します。

`--self-test` / `--stream-test` に人物の検証を追加しました。複数シード・全4方向の配置、生成された人物の床・壁・経路と配置間隔、60秒の歩行、会話による停止と再開、全文表示・終了・キャンセル、距離と視線と壁の判定、区画の解放と再訪を確認します。

会話ファイルだけの検証は`--dialogue-test`、人物の配置・動作を含む検証は`--resident-test`です。会話ファイルの検証は現行原稿の8会話・24ページを確認するため、件数を増やす場合は検証の期待件数も合わせて更新してください。

```powershell
dotnet run --project CAERO -c Debug -- --capture-people
dotnet run --no-build --project CAERO -c Debug -- --capture-people --night
```

最初の島の3人の姿と日本語会話の4視点を `SaveData/Captures/generated-people-*.png` に、夜は `generated-people-night-*.png` に保存します。撮影は現在のセーブを読み書きしません。
