# CAERO の人々と会話

白い質素なローブを着た老若男女が、島の地上、壁のない建物の1階・2階、橋の上にいます。外部モデルを使わず、共有する6つのメッシュから衣装・頭・手足・髪を描きます。長い袖と裾は不透明な薄い布として扱い、石材の目地は適用しません。世界と同じ霧・昼夜・灯籠の光に馴染ませ、影は追加しません。

## 姿と動き

20の会話と人物像を用意しています。座り込む7人・立ち尽くす6人・力なく歩く7人です。背丈・体格・髪・顔色を変え、下がった頭、閉じ気味の目、垂れた腕、小さな呼吸の動きを付けています。

歩く人は毎秒0.32単位で、検証済みの2.5単位の経路を往復します。会話中は相手の動きを止め、終了すると再開します。座り込む人は膝を立て、その上に腕を置き、背中を少し後ろへ預けます。専用のローブが腰・膝・足先を連続して覆い、裾が床まで広がります。立ち尽くす人は俯いたまま、その場でわずかに呼吸します。どちらも移動せず、話しかけられます。

人物には体格に応じて半径約0.19〜0.29単位の小さな円柱の当たり判定があります。座り姿は低く、少し前に中心を寄せます。幅3単位の空中回廊の中央にいても、左右を歩いて通れます。歩行・30倍速移動・飛行・上下からの接触で判定し、移動中の人物にも追従します。歩く人物はこちらにぶつかる手前で待ち、道が空くと再開します。

## 配置と所有権

最初の島も含めて全島で0〜5人を抽選します。9か所の固定候補は使わず、島シード（ワールドシードと区画座標）から床の範囲内の座標・向き・歩行方向を連続的に抽選します。対象は島の地上、壁のない大広間・建物の1階と2階、地上と空中の橋です。床の種類を抽選してから、その範囲内の位置を決めます。壁のある旧塔や高層塔の内部は、入口が開いていても対象外です。側翼は柱だけの回廊・ドーム・2層ギャラリー・パーゴラだけを対象にします。建築を生成する乱数列やマップの頂点は変えません。

最大192回まで安全な位置を探し、足場が不足した場合は配置人数を減らします。人物同士は歩行経路を含めて15単位以上離します。橋の区画境界の両側10単位には配置せず、別々に生成される隣の島の人物とも距離を保ちます。

配置時に、体全体の範囲と歩行経路を0.25単位刻みで調べます。中心・辺・四隅に同じ高さの床があり、壁や天井にぶつからず、許可された階の範囲を出ない候補だけ採用します。座り込む人は候補から12単位以内の既存の壁や柱を探し、腰と肩を支えられる面に背中を沿わせ、外側を向けます。移動先にも同じ階・建物の制限を適用するため、壁に寄せた結果として対象外の建物内へ入りません。座り姿専用の足場・衝突検証で前へ広がる裾と頭まで調べ、安全な背もたれがなければ元の候補で座ります。島の解放と同時に人物も管理対象から外れます。再訪時には同じ人物・開始位置から再生成します。会話履歴や歩行途中の位置はセーブしません。

## 操作と会話

3.4単位以内で正面にいる、壁に遮られていない最も近い人を選びます。プロンプトが出ているときにEで開始します。

- E / Space: 文字が出ている途中なら全文表示、表示済みなら次のページへ。
- Esc: 会話を閉じる。マウスの捕捉は保ちます。その後もう一度Escで通常のマウス解放になります。
- 最終ページの次へ進むと会話を閉じます。会話中は移動・視点・ジャンプを止め、Spaceがジャンプ音を発生させることも防ぎます。
- タイトルへ戻るときや、相手の区画の解放時には会話を閉じます。

20種類・各3ページ、合計60ページの日本語会話があります。疲れた佇まいに合わせながら、石や草の観察、灯籠、道を選ぶ迷い、会話の余韻、子どもの遊び、小さな冗談などを分担させています。話題と姿勢の対応は [DIALOGUE_PLAN.md](DIALOGUE_PLAN.md) にまとめています。島シードに基づく乱数で既定の会話を人物ごとに割り当て、会話中や再訪時に再抽選しません。音声読み上げや選択肢、クエストはありません。

## 外部会話ファイルの編集

開発時の原稿は [`CAERO/Content/dialogue.ja.json`](CAERO/Content/dialogue.ja.json)（UTF-8）です。ビルド・publish時に実行ファイルの隣の`Content/dialogue.ja.json`へコピーします。開発時は原稿を編集して再ビルド、配布版は同梱JSONを編集し、ゲームを再起動してください。起動中の自動再読み込みはありません。

ファイル全体は`version: 1`、`language: "ja"`、`conversations`配列で構成します。配列内の1会話の例:

```json
{
  "id": 0,
  "name": "白髪の老人",
  "age": "elder",
  "gender": "male",
  "pose": "sitting",
  "theme": "足音を聞く",
  "pages": [
    "座っていると、足音が先に届くんだ。\n君が来る少し前から、聞こえていたよ。",
    "急いでいる人も、ここでは歩幅が小さくなる。\n橋が長いせいか、考えごとのせいか。",
    "話してくれて、ありがとう。\n次は足音だけでも、君だとわかるかもしれない。"
  ]
}
```

- セリフの編集は`pages`、表示する呼称の編集は`name`です。`pages`は空でない3要素。改行はJSON文字列内の`\n`で指定でき、画面幅による自動折り返しもあります。640px幅でも表示できる短いページに分けています。
- `age`は`child` / `adult` / `elder`、`gender`は`male` / `female`、`pose`は`walking` / `sitting` / `standing`。会話に対応する人物の外見・姿勢にも反映するため、文体や呼称と合わせてください。
- `id`は配列の順番と一致する0始まりの連番です。再訪時にも同じ会話を選ぶため、既存IDを入れ替えず、追加時は末尾へ連番で追加します。最初の島も他の島と同じ抽選規則を使います。
- `theme`は編集・点検用の主題で、ゲーム画面には表示しません。ファイルは初回に一度だけ読み込んで共有し、島の生成ごとのファイルアクセスは行いません。
- ファイルがない場合やJSONの構文・ID・人物情報・ページ数が不正な場合は、黙って別の会話へ置き換えず、原因が分かるエラーにします。全く同じ3ページの会話の重複も検出します。

## 日本語表示と検証

Windowsの既存フォントを読み込み、会話で使用する文字だけをアトラスにします。TTCコレクションの最初の書体をメモリ上で取り出してraylibへ渡します。フォントファイルはプロジェクトや配布物にコピーしません。ウィンドウ幅に合わせて文字サイズと折り返しを調整します。

`--self-test` / `--stream-test` に人物の検証を追加しました。複数シード・全4方向の配置、生成された人物の床・壁・経路と配置間隔、60秒の歩行、会話による停止と再開、全文表示・終了・キャンセル、距離と視線と壁の判定、区画の解放と再訪を確認します。

配置検査は64島で人物ごとに60秒間、床の支持と体の空間を確認します。立ち姿は裾から頭までの範囲、座り姿は肩・袖も検査します。当たり判定は全姿勢・体格について、幅3単位の手すり付き回廊で左右の通り抜け、正面での停止、30倍速・飛行・落下、人物側の停止と再開を検証します。

会話ファイルだけの検証は`--dialogue-test`、人物の配置・動作を含む検証は`--resident-test`です。会話ファイルの検証は現行原稿の20会話・60ページを確認するため、件数を増やす場合は検証の期待件数も合わせて更新してください。

```powershell
dotnet run --project CAERO -c Debug -- --capture-people
dotnet run --no-build --project CAERO -c Debug -- --capture-people --night
```

最初の島の人物ごとの姿と日本語会話（0人の場合は島の風景）を `SaveData/Captures/generated-people-*.png` に、夜は `generated-people-night-*.png` に保存します。撮影は現在のセーブを読み書きしません。
